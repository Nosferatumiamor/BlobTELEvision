BlobTELEvision: local model weights (not in git).

Subfolders (diffusers layout, fp16 safetensors only):
  modelscope-t2v/   damo-vilab/text-to-video-ms-1.7b   (~3.7 GB)  text -> video
  i2vgen-xl/        ali-vilab/i2vgen-xl                (~5 GB)    image -> video (optional)

Install with the in-app "Download selected" button. Nothing is downloaded
automatically. After a manual download, create an empty file named
.blobtv_complete in the model's folder so the app recognises it as installed.
